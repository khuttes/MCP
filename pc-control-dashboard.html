      How to start

      1. Double-click Start-Helpyard.bat in the project folder.
      2. The launcher starts the local Python bridge, waits for it, and opens this page on the selected port.
      3. The browser completes a one-time, short-lived local connection automatically; the token is kept in memory only.
      4. Keep the minimized Helpyard window open. Close it or press Ctrl+C there to stop the bridge.
      5. Python 3.10+ is required. The bridge uses Python's standard library; no pip packages are needed. Ollama is optional.
